# Producer Map：我们手上工具的产生者归属

- 状态：**working**（2026-09-13 起）——一张**盘点表**，不是结论
- 用途：按"这条信息该由谁产生"逐个过一遍我们真正在用的能力，找**产生者重叠**，以及**唯一化之后能直接消掉哪个环节**
- 证据来源：本仓实测（`docs/status/*`）+ 外部研究对照（§4）
- 边界：本表属 runtime 线；"能力该长成什么形态"的结论属另一条线（插件/工具语义）。本表只到"谁产生、何时暴露"

---

## 0. 为什么要这张表

我们这条线一直只在答第二问（**这条事实何时暴露、以什么形态**），很少答第一问：

> **这条信息本来就该由谁产生？**

后果是可测的：c1–c6 那一列（1.54× ~ 6.20×、通道信誉归零）**全部是"两边都能产生"的账单**。
把它问清楚，一部分"暴露问题"会直接消失——不是被优化掉，是**不存在了**。

## 1. 四类重叠（本表的主轴）

| 类型 | 形态 | 谁和谁撞 | 代价 | 唯一化之后消掉什么 |
|---|---|---|---|---|
| **A 结论重叠** | 观测在 runtime，**结论两边都下** | runtime ↔ 模型 | 说服：c2 **1.54×**、c5 **5.08×**、c6 **6.20×**；模型被迫改口或硬化 | 整个"说服回合"消失 |
| **B 复述重叠** | 事实在 runtime，模型在上下文里**重述一遍** | runtime → 模型 → context | 来源漂移 + 多一个不必要的产生者（context 污染） | 转述这一步消失 |
| **C 装配重叠** | 内容由 runtime 产生，但模型能**重组/裁剪**出"看起来一样"的东西 | runtime ↔ 模型（程序里） | 形态保证失效（PTC 实测：`quoteBlock` 用了 **0** 次） | 组装也归 runtime，或保证落到可核对的值上 |
| **D 授权重叠** | 来源唯一，但"**它能不能决定这个动作**"没有唯一裁决者 | 任何来源 ↔ 决策 | 外部实测：可信/不可信变体动作不同 **5.4%**（竞争）/ **1.7%**（支持）；受控退化下 **2.4%** [2.1, 3.0] | "权威性提示"换成**授权范围** |

> A/B/C 的代价是本仓实测；D 的代价来自外部研究（§4 [2]），我们尚未自测。

## 3. C 类这个格子：我们量到但还没修的那一处

`citation_quote` 在 native 下交的是**一整句带声明的话**（引文＋出处＋"这是逐字的"），在 PTC 下交的是**零件**（`excerpt`／`contentHash`／`quoteBlock`／`note`）。
实测四臂：两臂逐字性都没坏，但 PTC 臂**从未使用工具自己的 `quoteBlock`**（代码里出现 0 次），而是自己拼了引注，还剪掉了引文开头的条号，并自述"这仍是逐字正文"。

要紧的不是"拼错没拼错"，而是：**"这句是逐字的"从随结果附带的声明，降级成了一个可以不管的字段。**
而 2607.20827 已经证明"文字的权威性提示控不住行为"——所以这句话本来就不该被当成保证用。

**C 类的两种修法**（二选一，都还没做）：

1. **让装配也成为 runtime 的动作**：模型给"引哪条"，成品由 runtime 出（`emit_report` 就是这个形态）。
2. **让保证落在能核对的值上**：`excerpt` + `contentHash` + 原文位置，让第三方自己核——不依赖任何一句声明。

## 5. 现在就能动的三件事

1. **A 类清零**：把 `pwsh`/测试类观测的**判定**从模型手里收回（"通过/不通过"由 runtime 出），模型只答"说明什么"。这是消掉说服回合最直接的一刀。
2. **B 类统一**：凡是 runtime 已有 canonical 值的事实（目标状态、子代结果、事实登记），上下文里**只放 canonical 表示**，禁止模型转述。
3. **C 类二选一**：给 `citation_quote` 这一族定形态——要么"成品由 runtime 出"，要么"保证落到 `contentHash`＋原文位置"。**不要停留在"工具交了一句话"这个中间态。**
